# AMG65 GIF → LED 点阵转模工具

一个纯前端的单文件 HTML 工具，用于把 GIF 动画转换为 MACHENIKE AMG65 键盘 63×5 LED 点阵屏可用的效果 JSON 文件。**全部在浏览器本地运行，无需安装任何东西，无任何网络请求。**

## 背景

键盘官方上位机自带 GIF 导入功能，但效果很差：

- 颜色识别质量低，导入后色彩严重失真
- 黑色区域不会被正确处理（不设为熄灭），整屏发灰

本工具自己实现了完整的 GIF 解码器（LZW / 逐帧 / 透明 / Disposal / 交错存储），逐帧拆解后按 LED 点阵精确取模，输出与官方格式完全一致的 JSON，颜色所见即所得。

## 使用方法

1. 下载 `gif2led.html`，用浏览器直接打开（推荐 Chrome / Edge）
2. 点击 **导入 GIF**，选择 GIF 文件
3. 在预览区拖动取景框，选择要映射到 LED 屏的区域
4. 按需调整参数（见下文），LED 实际显示区会实时预览
5. 点击 **导出 LED-XXXXXXXX.json**，将导出的 JSON 导入键盘上位机即可

```
┌──────────────────────────────────┐

├──────────────────────────────────┤
```

## 参数说明

### 取景

| 参数 | 说明 |
|---|---|
| 取景框宽度占比 | 30%–400%。>100% 时取景框大于 GIF，超出部分以黑边补齐（适合把小图缩小放进屏幕） |

### 采样方式（核心）

| 模式 | 原理 | 适用 |
|---|---|---|
| **1:1 点阵** | 每颗 LED 精确对应 GIF 的一个像素，零混合零丢失 | GIF 本身就是点阵屏形式的素材（推荐默认） |
| 主色（众数） | 格子内出现次数最多的颜色（5bit/通道分桶抗噪） | 像素图、图标、纯色块动效 |
| 中心取点 | 取格子正中像素 | 像素图且对位准确时最锐利 |
| 最亮 | 取格子内亮度最高的像素 | 深色背景上的细线条/文字，防被背景吃掉 |
| 平均 | sRGB 线性空间求均值（暗部不发灰） | 照片、渐变类 |

### 量化（适配 LED 屏的低灰度特性）

| 参数 | 说明 |
|---|---|
| 黑场阈值 | 正值：亮度低于该值的像素压为纯黑（熄灭）；**负值**：黑场抬升，暗部微亮而非完全熄灭 |
| 对比度 | -100~100，围绕中灰拉伸。+100 接近非黑即白硬切 |
| 色阶数 | 每通道保留的级数，2=纯色（0/255）。LED 屏灰度表现差，红黑交界 GIF 建议 2 级，交界处不再出现中间灰度 |

### 播放

| 参数 | 说明 |
|---|---|
| 速度 speed | 写入 JSON 的 speed 字段（样本值 90） |
| 亮度 brightness | 写入 JSON 的 brightness 字段（样本值 255） |
| 帧率倍速 | 预览播放速度，不影响导出（导出沿用 GIF 原始帧延时对应的 speed） |

## 输出格式

与官方效果文件完全同构：

```json
{
  "MACHENIKE": "68 LED",
  "led effects": [
    {
      "brightness": 255,
      "speed": 90,
      "frames": [
        { "frameIndex": 0, "frameRGB": ["#FF0000", "...共 315 个"] },
        { "frameIndex": 1, "frameRGB": ["..."] }
      ]
    }
  ]
}
```

- 每帧 **315** 个颜色值（63 列 × 5 行，行优先排列）
- 颜色格式 `#RRGGBB`，黑色 `#000000` 表示不点亮

## 特性

- **纯单文件**：无依赖、无构建、离线可用
- **自带 GIF 解码器**：LZW 解码、多帧、透明色、Disposal 恢复方式（0-3）、交错存储还原，全部手写实现
- **实时预览**：所有参数拖动即时刷新 LED 点阵预览
- **像素友好**：多种采样模式适配像素图 / 点阵图 / 照片类素材
